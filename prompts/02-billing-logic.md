# Task 02 — ตรรกะการคิดเงินและราคา

**เป้าหมาย:** ตรวจว่าสูตรคิดราคา/ยอดวางบิลถูกต้องตามกติกาทางธุรกิจที่ตั้งใจไว้หรือไม่

## ตารางที่เกี่ยวข้อง (D02)

`ข้อมูลการวางบิล` · `ปริ๊นใบวางบิล` · `ราคาในระบบก่อนส่งสินค้า` · `ราคาน้ำมันดีเซล` · `Price_Table` · `PriceOverride`

## ขั้นที่ต้องทำ

1. อ่าน `app/tables/ราคาในระบบก่อนส่งสินค้า.json` และ `ราคาน้ำมันดีเซล.json` → หาแนวคิดของราคา 3 ชั้น
2. อ่าน `PriceOverride.json` → เข้าใจว่า override ราคาทำงานอย่างไร (ช่วงวันที่ + ชื่องาน)
3. อ่าน `ปริ๊นใบวางบิล.json` → ดู `ราคารวม` (มี App formula ยาว) และดูว่ามีอะไรผิด
4. ตรวจกรณีที่ผลคำนวณเป็น 0 หรือว่างโดยไม่ได้ตั้งใจ (เช่น ราคาน้ำมันย้อนหลังไม่มีข้อมูล)

## คำถามที่ต้องตอบ

- โครงสร้างราคาที่ถูกต้องควรเป็นอย่างไร (เรียงชั้น: ราคาตามระยะทาง → ราคาน้ำมัน → override → ส่วนเพิ่ม)
- กฎทางธุรกิจที่ฝังอยู่ในสูตร (เช่น "ใช้ราคาวันที่ 25 ของเดือนก่อน") ควรย้ายไปที่ไหน
- จุดที่ผลคำนวณผิดได้เงียบ ๆ (silent) และจะทำให้ยอดเงินผิด
- สูตรที่ยาว/ซ้อนกันลึก ควรแตกเป็นคอลัมน์ช่วยอะไรบ้าง

## ข้อควรระวัง

- `ANY(SELECT(...))` ใน Appsheet คืนค่าบูลีน ไม่ใช่ค่าตัวเลข — ตรวจให้ดีว่าจะเอาไปใช้คิดเงินจริงหรือไม่
- อย่าคิดว่าสูตรยาว = ผิด บางสูตรยาวเพราะซับซ้อนจริง — ต้องอธิบายว่ายาวตรงไหน
