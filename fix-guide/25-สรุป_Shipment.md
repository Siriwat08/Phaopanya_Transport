## 🚨 ปัญหาระดับตาราง (แก้ก่อนรายคอลัมน์)

### 🚨 ปัญหา 1: 🟠 [MEDIUM] ตารางไม่มี Security filter → ผู้ใช้ทุกบทบาทเห็นข้อมูลทุกแถว

- **ทำไมสำคัญ:** Security filter คือด่านตัดข้อมูลที่ฝั่งเซิร์ฟเวอร์ ถ้าไม่มี ทุกแถวถูกดาวน์โหลดลงเครื่องทุกผู้ใช้ แม้หน้าจอซ่อนไว้ก็หลุดผ่านวิวอื่นได้
- **วิธีแก้ทีละขั้น (จุดแก้:** `Data ▸ Tables ▸ คลิกตารางนี้ ▸ ช่อง "Security filter"`):**
   1. คลิกช่อง "Security filter" (ถ้าไม่มีช่องนี้ คลิก + สร้างในกลุ่ม Table settings หรือแก้ผ่าน "Table properties")
   2. วางสูตรด้านล่าง — ปรับ [Email พนักงาน] เป็นชื่อคอลัมน์อีเมลของตารางนี้ให้ตรง
   3. กด Save — ทดสอบด้วยบัญชี USER ว่าเห็นเฉพาะแถวของตัวเอง

**สูตรที่ใช้ (คัดลอกไปวางได้):**

```
=OR(USERROLE() = "ADMIN", [Email พนักงาน] = USEREMAIL())
```

- **ตรวจว่าแก้สำเร็จ:** ล็อกอินด้วย USER แล้วตรวจว่าเห็นเฉพาะแถวของตัวเอง

### 🚨 ปัญหา 2: 🟠 [MEDIUM] ไม่มี Expression for update mode → ค่าเริ่มต้น ALL_CHANGES ผู้ใช้ทุกคนแก้/ลบได้

- **ทำไมสำคัญ:** การลบแถวใน no-code ย้อนกลับยาก ควรจำกัดสิทธิ์ลบให้ ADMIN
- **วิธีแก้ทีละขั้น (จุดแก้:** `Data ▸ Tables ▸ คลิกตารางนี้ ▸ ช่อง "Expression for update mode"`):**
   1. คลิกช่อง "Expression for update mode"
   2. วางสูตรด้านล่าง (USER จะเพิ่ม/แก้ได้ แต่ลบไม่ได้)
   3. Save แล้วทดสอบลบแถวด้วยบัญชี USER ต้องถูกบล็อก

**สูตรที่ใช้ (คัดลอกไปวางได้):**

```
=SWITCH(USERROLE(), "ADMIN", "ALL_CHANGES", "USER", "ADDS_AND_UPDATES", "READ_ONLY")
```

- **ตรวจว่าแก้สำเร็จ:** ลองลบแถวด้วย USER ธรรมดา ต้องลบไม่ได้

### 🚨 ข้อค้นพบ 3 (วิเคราะห์พื้นฐาน) [ต้องปรับปรุง] ตารางนี้ไม่มี Security filter ทำให้ผู้ใช้ทุกบทบาท (USER) เห็นข้อมูลทั้งหมด

- **ผลต่องาน:** ข้อมูลข้ามผู้ใช้หลุดรั่ว — ทั้งข้อมูลงานและข้อมูลลูกค้า
- **วิธีแก้:** ตั้ง Security filter ให้เหมือนตารางหลักของแอป

**สูตรแนะนำ:**

```
=OR(USERROLE() = "ADMIN", [Email พนักงาน] = USEREMAIL())
```

### 🚨 ข้อค้นพบ 4 (วิเคราะห์พื้นฐาน) [ต้องปรับปรุง] ไม่มี Expression for update mode → ค่าเริ่มต้น ALL_CHANGES ทำให้ผู้ใช้ทุกคนแก้/ลบข้อมูลได้

- **ผลต่องาน:** ผู้ใช้ทั่วไปแก้ไขหรือลบแถวได้ โดยไม่ได้รับการควบคุม
- **วิธีแก้:** เพิ่ม Expression for update mode ให้ USER เป็น READ_ONLY หรือ ADDS_AND_UPDATES

**สูตรแนะนำ:**

```
=SWITCH(USERROLE(), "ADMIN", "ALL_CHANGES", "USER", "READ_ONLY", "READ_ONLY")
```
