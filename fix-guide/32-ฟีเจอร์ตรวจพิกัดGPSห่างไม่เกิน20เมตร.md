## 📋 1) สรุปความต้องการของคุณ (ยืนยันความเข้าใจก่อนลงมือ)

สิ่งที่คุณต้องการ คือ ระบบตรวจสอบพิกัดตอนพนักงานบันทึกงานส่งสินค้า ซึ่งทำงานตามลำดับนี้:

```
พนักงานเปิดฟอร์ม "SCGนครหลวงJWDภูมิภาค"
        │
        ▼

        │
        ▼

│  คอลัมน์ LatLong_Actual (ชีตตารางงานประจำวัน) มีข้อมูลหรือไม่?  │
└─────────────────────────────────────────────────────────────┘
        │                              │
     ไม่มีข้อมูล                     มีข้อมูล (13.345678, 100.987654)
        │                              │
        ▼                              ▼
   บันทึกได้ปกติ            คำนวณระยะห่างระหว่าง:
   (ไม่มีพิกัดให้เทียบ)      จุดส่งสินค้าปลายทาง (ชีต SCG) ↔ LatLong_Actual
                                       │
                        ┌──────────────┴──────────────┐
                   ห่าง ≤ 20 เมตร                ห่าง > 20 เมตร
                        │                              │

                 บันทึก (SAVE) ได้         ❌ ห้ามบันทึก — ขึ้นข้อความเตือน
                                                │

| คำถามของคุณ | คำตอบสั้น |
|---|---|
| ต้องเพิ่มคอลัมน์มั้ย? | **ต้องครับ** — เพิ่ม 3 คอลัมน์จริง + 1 คอลัมน์เสมือน (ขั้นที่ 1-2) |

| อยากได้ข้อความ "มีแก้ไข โดยคนนี้"? | ได้ — คอลัมน์ `ยืนยันตำแหน่ง_โดย` + `ยืนยันตำแหน่ง_เวลา` + แถวสีส้ม + ข้อความในปุ่มยืนยัน (ขั้นที่ 5-6) |
| ต้องแก้แผน/แผนที่เดิมมั้ย? | **ไม่ต้องรื้อ** — เป็นการ "เพิ่มเข้าไป" เท่านั้น มีจุด merge อยู่แค่ 1 จุด (สูตร Valid_If ขั้นที่ 3) และผมอัปเดตไฟล์ 01, 05, index, 00 ให้แล้ว |

## 🔍 2) ผลการวิเคราะห์ข้อมูลจริงของ 2 ชีต (จาก repo ของคุณ)

### 2.1 ชีต `ตารางงานประจำวัน` — ฝั่ง "พิกัดอ้างอิงจริง"

| คอลัมน์ | ชนิดจริงในแอป | บทบาทในฟีเจอร์นี้ |
|---|---|---|
| `ID_งานประจำวัน` | Text, Initial `=UNIQUEID()` | **Key ของตาราง** — ถูกอ้างถึงโดย SM_Link_SCG |
| `LatLong_Actual` | **LatLong** ✓ | พิกัดจริงของปลายทาง — เก็บแบบเต็ม `13.345678, 100.987654` ตามที่คุณต้องการ |
| `Invoice No` | Text | ตัวเชื่อมกับชีต SCG (แอปใช้อยู่แล้ว) |
| `LatLong_Actual_Status` | Text | คอลัมน์สถานะพิกัด (มีอยู่แล้ว ไม่ต้องแก้) |

**ข้อสังเกตจากการตรวจ:** ไม่พบ Action หรือ Bot ในแอปที่เขียนค่าลง `LatLong_Actual` แปลว่าค่านี้ถูกเติมจาก **ฝั่ง Google Sheet (สูตร/สคริปต์) หรือป้อนเอง** — ไม่เป็นปัญหาต่อฟีเจอร์นี้ เพราะเราแค่ "อ่านค่า" มาเทียบ แต่ควรรู้ไว้ว่าถ้าชีตต้นทางยังไม่มีค่า ระบบจะข้ามการตรวจให้เอง (ปลอดภัย ไม่บล็อกงาน)

### 2.2 ชีต `SCGนครหลวงJWDภูมิภาค` — ฝั่งที่ต้องตรวจ

| คอลัมน์ | ชนิดจริงในแอป | บทบาทในฟีเจอร์นี้ |
|---|---|---|
| `จุดส่งสินค้าปลายทาง` | **LatLong** ✓, Initial `=HERE()`, **Editable_If: `=USERROLE()="ADMIN"`** | พิกัดที่จับอัตโนมัติตอนพนักงานเปิดฟอร์ม (ปล่อย Editable_If เดิมไว้ได้ — การตรวจยังทำงานกับค่า auto ได้ปกติ) |
| `SM_Link_SCG` | **Ref → ตารางงานประจำวัน** (จับคู่ด้วย Invoice No ตัวแรก) | **สายพานดึงข้อมูลที่แอปมีอยู่แล้ว** — เราจะใช้ `[SM_Link_SCG].[LatLong_Actual]` โดยไม่ต้องเขียน LOOKUP ใหม่ |
| `พิกัดตอนกดบันทึกงาน` | LatLong, Initial `=HERE()` | แยกจากฟีเจอร์นี้ (ใช้ตรวจ "ระยะขยับ" เดิม — ไม่กระทบ) |
| `ระยะขยับจากจุดเริ่มต้น_เมตร` | App formula `=DISTANCE(...) * 1000` | **หลักฐานว่าแอปใช้แพทเทิร์น DISTANCE×1000 อยู่แล้ว** — สูตรใหม่ของเราจึงเข้ากับสไตล์เดิม |
| `พิกัดตอนกดบันทึก_เปลี่ยนแล้ว` | Yes/No + App formula | แพทเทิร์น "ธงบอกสถานะ" ที่แอปมีอยู่แล้ว — คอลัมน์ยืนยันใหม่ของเราออกแบบตามสไตล์นี้ |

### 2.3 ข้อเท็จจริงที่ยืนยันแล้ว (มีผลต่อการออกแบบ)

1. **`DISTANCE(a, b)` คืนค่าเป็น "กิโลเมตร"** (เอกสารทางการ Google AppSheet) → คูณ 1000 เพื่อได้ "เมตร" — เกณฑ์ 20 เมตร = `DISTANCE(...) * 1000 <= 20`
2. **AppSheet ไม่มีปุ่ม Action ใน Form view อย่างเป็นทางการ** (ยืนยันจาก Google Developer Forum — คำตอบทางการคือ No, ล่าสุด ส.ค. 2024) → เราจึงใช้ **คอลัมน์ Yes/No ทำหน้าที่เป็น "สวิตช์/ปุ่มยืนยัน" ในฟอร์ม** ซึ่งให้ UX เหมือนกันเป๊ะ: เห็นว่าห่างเกิน → กดยืนยัน → กด SAVE ผ่าน แล้วเพิ่ม **ปุ่ม Action จริง** ไว้บนหน้ารายละเอียด/ตารางสำหรับยืนยัน "หลังบันทึกแล้ว" (พร้อมข้อความยืนยันตามที่คุณขอ)
3. **Valid_If เดิมของ `จุดส่งสินค้าปลายทาง` ต้อง merge** (แอปมีเช็คค่าว่าง/พิกัด 0,0 อยู่แล้ว) — ในขั้นที่ 3 ผมให้ "สูตรเต็มหลัง merge" แบบ copy ทีเดียวจบ
4. **Security filter ของทั้ง 2 ตาราง** คือ `[Email พนักงาน] = USEREMAIL()` → พนักงานเห็นเฉพาะงานของตัวเอง การ deref ผ่าน SM_Link_SCG จึงปลอดภัยและเร็ว (แต่ดูข้อควรระวัง 14.4 ด้วย)

## 🧩 3) คำตอบละเอียด 3 คำถามสำคัญ

### 3.1 ต้องเพิ่มคอลัมน์มั้ย? → **ต้องครับ 4 คอลัมน์** (เพิ่มในตาราง `SCGนครหลวงJWDภูมิภาค` เท่านั้น)

| # | ชื่อคอลัมน์ใหม่ | ชนิด | แบบ | หน้าที่ |
|---|---|---|---|---|
| 1 | `ระยะห่างพิกัดจริง_เมตร` | Decimal | **Virtual (เสมือน)** | คำนวณระยะห่างครั้งเดียว ใช้ซ้ำได้ทุกที่ (Valid_If / ข้อความเตือน / Show_If / ปุ่ม / Format Rule) — แก้สูตรที่เดียว ทั้งระบบเปลี่ยนตาม |
| 2 | `ยืนยันตำแหน่ง_ด้วยตนเอง` | Yes/No | จริง (เก็บในชีต) | **"ปุ่มยืนยัน" ในฟอร์ม** — โผล่เฉพาะเมื่อห่างเกิน 20 เมตร |
| 3 | `ยืนยันตำแหน่ง_โดย` | Email | จริง (เก็บในชีต) | **"มีแก้ไข โดยคนนี้"** — อีเมลผู้ที่กดยืนยัน (คำนวณอัตโนมัติ) |
| 4 | `ยืนยันตำแหน่ง_เวลา` | DateTime | จริง (เก็บในชีต) | **เวลาที่กดยืนยัน** (คำนวณอัตโนมัติ) |

> **ทำไมคอลัมน์ 2-4 ต้องเป็น "จริง" ไม่ใช่เสมือน?** เพราะต้องเก็บถาวรลง Google Sheet เป็นหลักฐาน audit — คอลัมน์เสมือนไม่ถูกบันทึกลงชีต ค่าจะหายเมื่อปิดแอป

### 3.2 ทำไมใช้ "สวิตช์" แทน "ปุ่ม Action" ในฟอร์ม?

AppSheet **ไม่อนุญาตให้ปุ่ม Action ปรากฏใน Form view** (นี่คือข้อจำกัดของแพลตฟอร์ม ไม่ใช่ข้อผิดพลาดของแอปคุณ) วิธีเดียวที่ทำงานได้ 100% ทุกอุปกรณ์คือคอลัมน์ Yes/No ซึ่งแสดงเป็น **สวิตช์เลื่อนได้ (toggle switch)** ในฟอร์ม — เราตั้ง Show_If ให้ **โผล่เฉพาะตอนห่างเกิน 20 เมตรเท่านั้น** พนักงานจึงไม่สับสนว่าต้องกดตอนไหน

และเพื่อให้ได้ "ปุ่ม" ตามที่คุณอยากได้จริง ๆ ผมเพิ่ม **ขั้นที่ 5: ปุ่ม Action จริง "ยืนยันตำแหน่งปลายทางถูกต้อง"** ไว้บนหน้ารายละเอียด (Detail) และแถวตาราง — มี **ข้อความยืนยันก่อนกด** ว่า *"มีการยืนยันแก้ไข โดย [อีเมล] เมื่อ [วันเวลา]"* เหมือนที่คุณขอมา ใช้กับกรณีบันทึกไปแล้วและต้องการยืนยันย้อนหลัง

### 3.3 ต้องแก้แผนเดิมก่อนมั้ย? → **ไม่ต้อง — "เพิ่มแผนนี้เข้าไปได้เลย"**

| ของเดิม | ผลกระทบ | ต้องทำอะไร |
|---|---|---|
| แผนที่ (Map view `View Map (จุดส่งสินค้าปลายทาง)`) | ไม่กระทบเลย | ไม่ต้องแก้ — แผนที่ยังโชว์พิกัดเดิมปกติ |
| แผนปรับปรุง 3 ระยะ (ในรายงาน 00) | ไม่ขัดแย้ง | ทำระยะ 1 (แก้บั๊ก) เสร็จก่อน แล้วทำฟีเจอร์นี้ได้เลย — หรือทำก่อนก็ได้ เพราะตารางนี้มีบั๊กอยู่ 1 ข้อ (`Invoice No`) ที่ไม่เกี่ยวกัน |
| สูตร Valid_If เดิมของ `จุดส่งสินค้าปลายทาง` | **จุดเดียวที่ต้อง merge** | แทนที่ด้วย "สูตรเต็มหลัง merge" ในขั้นที่ 3 (copy ทีเดียวจบ ไม่ต้องคิดเอง) |
| เช็คลิสต์/รายการคอลัมน์ในไฟล์คู่มือ 01 | ต้องเพิ่มรายการใหม่ | ✅ ผมอัปเดตไฟล์ 01, 05, index, 00 ให้แล้วเรียบร้อย |

## 📐 ขั้นที่ 1: สร้างคอลัมน์เสมือน `ระยะห่างพิกัดจริง_เมตร`

**จุดแก้:** `Data ▸ SCGนครหลวงJWDภูมิภาค ▸ Columns ▸ ปุ่ม "+ Virtual Column..."` (บรรทัดบนสุดของรายการคอลัมน์)

1. กด **"+ Virtual Column..."** จะเห็นแถวคอลัมน์ใหม่เพิ่มขึ้นมาท้ายสุด
2. ตั้งค่าตามตารางนี้ให้ครบทุกช่อง:

| ช่องตั้งค่า | ค่าที่ต้องใส่ |
|---|---|
| **NAME** | `ระยะห่างพิกัดจริง_เมตร` |
| **TYPE** | `Decimal` |
| **FORMULA** | *(สูตรด้านล่าง)* |
| **SHOW?** | เปิด (Yes) |
| **READ-ONLY?** | เปิดอัตโนมัติ (คอลัมน์เสมือนมีสูตรแก้ค่าไม่ได้อยู่แล้ว) |

**สูตร (copy ทั้งกล่องไป paste ในช่อง FORMULA):**

```
IF(
  AND(
    ISNOTBLANK([SM_Link_SCG].[LatLong_Actual]),
    ISNOTBLANK([จุดส่งสินค้าปลายทาง])
  ),
  DISTANCE([SM_Link_SCG].[LatLong_Actual], [จุดส่งสินค้าปลายทาง]) * 1000,
  ""
)
```

**อ่านสูตรทีละบรรทัด (ฉบับมือใหม่):**

- `ISNOTBLANK([SM_Link_SCG].[LatLong_Actual])` — ตรวจว่าชีตตารางงานประจำวันมีพิกัดจริงมาให้เทียบหรือยัง (ข้อกำหนดของคุณ: "ถ้ามีข้อมูลอยู่")
- `ISNOTBLANK([จุดส่งสินค้าปลายทาง])` — กันหาค่า DISTANCE ตอนพิกัดของแถวนี้ยังว่าง
- `DISTANCE(..., ...) * 1000` — คำนวณระยะห่าง (DISTANCE ให้ผลเป็นกิโลเมตร → คูณ 1000 = เมตร)
- `, ""` — ถ้าเงื่อนไขไม่ครบ ให้ค่าว่าง (ระบบจะข้ามการตรวจ ไม่บล็อกงาน)

**ตรวจว่าแก้สำเร็จ:** กด **Save** → ในแท็บ Data ควรเห็นคอลัมน์ใหม่มีไอคอนสัญลักษณ์ ƒ (เสมือน) — ถ้า Editor ขึ้น error ให้เช็คว่า paste สูตรครบทุกวงเล็บ

## 📐 ขั้นที่ 2: เพิ่ม 3 คอลัมน์จริง (สวิตช์ยืนยัน + ใครกด + เมื่อไร)

**จุดแก้:** `Data ▸ SCGนครหลวงJWDภูมิภาค ▸ Columns ▸ ปุ่ม "+ Add" ▸ "Add column"` (เพิ่มคอลัมน์จริง ไม่ใช่ Virtual)

> 📌 เพิ่มคอลัมน์จริง 3 ตัว **ทีละตัว** ตามลำดับด้านล่าง แต่ละตัวใช้ตารางตั้งค่าของมันเอง

### 2-A) คอลัมน์ `ยืนยันตำแหน่ง_ด้วยตนเอง` (สวิตช์ยืนยัน = "ปุ่ม" ในฟอร์ม)

| ช่องตั้งค่า | ค่าที่ต้องใส่ |
|---|---|
| **NAME** | `ยืนยันตำแหน่ง_ด้วยตนเอง` |
| **TYPE** | `Yes/No` |
| **INITIAL VALUE** | `=FALSE` |
| **FORMULA** (App formula) | **เว้นว่าง** — อย่าใส่อะไร ต้องปล่อยให้คนกดเองได้ |
| **EDITABLE?** | เปิด (Yes) |
| **SHOW?** | เปิด (Yes) |
| **SHOW_IF** | *(สูตรด้านล่าง)* |
| **DESCRIPTION** | `เปิดสวิตช์นี้เฉพาะเมื่อคุณยืนยันว่าพิกัดจุดส่งสินค้าปลายทางที่ระบบแสดงถูกต้อง แม้ตำแหน่งปัจจุบันห่างเกิน 20 เมตร — ระบบจะบันทึกชื่อผู้ยืนยันและเวลาอัตโนมัติ` |

**สูตร SHOW_IF (copy ไป paste ในช่อง Show if):**

```
AND(
  ISNOTBLANK([SM_Link_SCG].[LatLong_Actual]),
  ISNUMBER([ระยะห่างพิกัดจริง_เมตร]),
  [ระยะห่างพิกัดจริง_เมตร] > 20
)
```

**อ่านสูตร:** สวิตช์จะ **โผล่เฉพาะเมื่อมีพิกัดอ้างอิง และระยะห่างเกิน 20 เมตร** เท่านั้น — พนักงานที่อยู่ตรงจุดถูกต้อง (≤20 ม.) จะไม่เห็นสวิตช์นี้เลย ไม่ต้องสับสน

### 2-B) คอลัมน์ `ยืนยันตำแหน่ง_โดย` (ใครกดยืนยัน — คำตอบของ "มีแก้ไข โดยคนนี้")

| ช่องตั้งค่า | ค่าที่ต้องใส่ |
|---|---|
| **NAME** | `ยืนยันตำแหน่ง_โดย` |
| **TYPE** | `Email` |
| **FORMULA** (App formula) | *(สูตรด้านล่าง)* |
| **EDITABLE?** | ปิดอัตโนมัติ (มี App formula = ระบบคำนวณ ห้ามคนพิมพ์ทับ) |
| **SHOW?** | เปิด (Yes) — ให้เห็นในหน้ารายละเอียดว่าใครเป็นคนยืนยัน |

**สูตร (paste ในช่อง FORMULA):**

```
IF([ยืนยันตำแหน่ง_ด้วยตนเอง] = TRUE, USEREMAIL(), "")
```

**อ่านสูตร:** ถ้าสวิตช์ยืนยันถูกเปิดอยู่ → จดอีเมลของคนที่กด Save ณ ตอนนั้น; ถ้าไม่ได้ยืนยัน → ค่าว่าง

### 2-C) คอลัมน์ `ยืนยันตำแหน่ง_เวลา` (กดยืนยันตอนไหน)

| ช่องตั้งค่า | ค่าที่ต้องใส่ |
|---|---|
| **NAME** | `ยืนยันตำแหน่ง_เวลา` |
| **TYPE** | `DateTime` |
| **FORMULA** (App formula) | *(สูตรด้านล่าง)* |
| **EDITABLE?** | ปิดอัตโนมัติ (มี App formula) |
| **SHOW?** | เปิด (Yes) |

**สูตร (paste ในช่อง FORMULA):**

```
IF([ยืนยันตำแหน่ง_ด้วยตนเอง] = TRUE, NOW(), "")
```

> 🔎 **หมายเหตุ:** สูตรนี้เก็บ "เวลาครั้งล่าสุดที่บันทึกโดยยืนยันมือ" ซึ่งเพียงพอกับการตรวจสอบย้อนหลัง ถ้าอยากเก็บ "เวลาครั้งแรกที่ยืนยัน" ตลอดไป ให้ใช้สูตรขั้นสูงนี้แทน (เลือกอย่างใดอย่างหนึ่ง):
>
> ```
> IF(
>   [ยืนยันตำแหน่ง_ด้วยตนเอง] = TRUE,
>   IF(ISBLANK([_THISROW_BEFORE].[ยืนยันตำแหน่ง_เวลา]), NOW(), [_THISROW_BEFORE].[ยืนยันตำแหน่ง_เวลา]),
>   ""
> )
> ```

**ตรวจว่าแก้สำเร็จ:** กด **Save** → รายการคอลัมน์ต้องมี `ยืนยันตำแหน่ง_ด้วยตนเอง` (Yes/No), `ยืนยันตำแหน่ง_โดย` (Email), `ยืนยันตำแหน่ง_เวลา` (DateTime) ต่อท้ายตาราง

**เช็ค Google Sheet:** เปิด Google Sheet ต้นทาง ชีต `SCGนครหลวงJWDภูมิภาค` — AppSheet จะเติมหัวคอลัมน์ 3 ช่องนี้ให้อัตโนมัติหลัง sync ครั้งแรก ถ้าไม่โผล่ภายใน 2-3 นาที ให้เพิ่มหัวคอลัมน์เอง 3 ช่อง (พิมพ์ชื่อตรงตามนี้เป๊ะ ๆ ในช่องหัวตารางท้ายสุด) แล้วกด `Data ▸ ตารางนี้ ▸ Regenerate schema`

## 🔒 ขั้นที่ 3: สูตร Valid_If ตรวจระยะ 20 เมตร (จุด merge กับแผนเดิม — สูตรเต็ม)

**จุดแก้:** `Data ▸ SCGนครหลวงJWDภูมิภาค ▸ Columns ▸ คลิกไอคอนดินสอ (pencil) ที่คอลัมน์ "จุดส่งสินค้าปลายทาง"`

> ⚠️ **อ่านก่อน:** คอลัมน์นี้ **มี Valid_If เดิมอยู่แล้ว** (`AND(ISNOTBLANK([_THIS]), [_THIS] <> "0.000000, 0.000000", [_THIS] <> "0, 0")`) — ห้ามลืมของเดิม! สูตรด้านล่างคือ **ฉบับเต็มหลัง merge แล้ว** (ของเดิม + ตรวจ 20 เมตร + ทางออกยืนยัน) — copy ทับช่อง Valid if ได้เลย

**สูตร VALID IF (copy ทั้งกล่อง):**

```
AND(
  ISNOTBLANK([_THIS]),
  [_THIS] <> "0.000000, 0.000000",
  [_THIS] <> "0, 0",
  OR(
    ISBLANK([SM_Link_SCG].[LatLong_Actual]),
    [ยืนยันตำแหน่ง_ด้วยตนเอง] = TRUE,
    AND(
      ISNUMBER([ระยะห่างพิกัดจริง_เมตร]),
      [ระยะห่างพิกัดจริง_เมตร] <= 20
    )
  )
)
```

**อ่านสูตรทีละส่วน:**

- บรรทัด 1-4 (ของเดิม — เก็บไว้เหมือนเดิมทุกตัวอักษร): ห้ามค่าว่าง / ห้ามพิกัด 0,0
- `ISBLANK([SM_Link_SCG].[LatLong_Actual])` — **ทางผ่านที่ 1:** ชีตตารางงานประจำวันยังไม่มีพิกัดให้เทียบ → ปล่อยผ่าน (ตามที่คุณกำหนด "ถ้ามีข้อมูลอยู่" ค่อยเช็ค)
- `[ยืนยันตำแหน่ง_ด้วยตนเอง] = TRUE` — **ทางผ่านที่ 2:** พนักงานกดสวิตช์ยืนยันแล้ว → ปล่อยผ่าน + ระบบจดว่าใครกด
- `[ระยะห่างพิกัดจริง_เมตร] <= 20` — **ทางผ่านที่ 3:** อยู่ห่างไม่เกิน 20 เมตร → ปล่อยผ่านตามปกติ

**ต่อในหน้าตั้งค่าคอลัมน์เดิม ให้ตั้งข้อความแจ้งเตือนเมื่อตรวจไม่ผ่าน:**

| ช่องตั้งค่า | ค่าที่ต้องใส่ |
|---|---|
| **INVALID VALUE ERROR** | *(สูตรด้านล่าง — ข้อความแบบไดนามิก บอกระยะจริงด้วย)* |

**สูตรข้อความเตือน (copy ทั้งกล่อง):**

```
CONCATENATE(
  "⚠️ ตำแหน่งปัจจุบันห่างจากพิกัดจริงของปลายทาง (LatLong_Actual) เกิน 20 เมตร",
  IF(
    ISNUMBER([ระยะห่างพิกัดจริง_เมตร]),
    CONCATENATE(" — ระยะที่ตรวจพบประมาณ ", ROUND([ระยะห่างพิกัดจริง_เมตร]), " เมตร"),
    ""
  ),
  " ถ้าตำแหน่งจุดส่งสินค้าปลายทางที่แสดงอยู่ถูกต้อง ให้เปิดสวิตช์ [ยืนยันตำแหน่ง_ด้วยตนเอง] แล้วกด SAVE อีกครั้ง"
)
```

**ตรวจว่าแก้สำเร็จ:** กด Save → เปิดแอป (โหมดพรีวิว) → เลือกงานที่รู้ว่าพิกัดห่างเกิน 20 เมตร → ฟอร์มต้องขึ้นข้อความเตือนใต้ช่อง `จุดส่งสินค้าปลายทาง` และ **กด SAVE ไม่ได้** → ขั้นที่ 4-6 จะเพิ่ม "ปุ่มยืนยัน" ให้ผ่านได้

## 🔘 ขั้นที่ 4 (อยู่ในขั้นที่ 2 แล้ว — ข้ามได้): ทบทวนสวิตช์ยืนยัน

สวิตช์ `ยืนยันตำแหน่ง_ด้วยตนเอง` ที่เพิ่มไว้ในขั้นที่ 2-A คือ "ปุ่มยืนยัน" ของเราในฟอร์ม ทำงานประสานกับสูตรขั้นที่ 3 แบบนี้:

```
ห่าง > 20 เมตร
  → Valid_If ติด → SAVE ไม่ได้ + สวิตช์โผล่มา (Show_If เห็นเงื่อนไขเดียวกัน)
  → พนักงานเลื่อนสวิตช์ ON → ระบบเตรียมจด [ยืนยันตำแหน่ง_โดย] + [ยืนยันตำแหน่ง_เวลา]
  → กด SAVE ผ่าน ✓
```

ทั้ง Valid_If (ขั้นที่ 3) และ Show_If (ขั้นที่ 2-A) ใช้เงื่อนไขระยะห่าง **เดียวกัน** จึงไม่มีทางเกิดสถานการณ์ "สวิตช์ไม่โผล่แต่ SAVE ติด" หรือ "สวิตช์โผล่แต่ SAVE ผ่านอยู่แล้ว" — ถ้าในอนาคตอยากเปลี่ยน 20 เมตรเป็นเลขอื่น ให้แก้ 3 จุด: Valid_If, Show_If ของสวิตช์ และเงื่อนไขปุ่ม Action (ขั้นที่ 5)

## 🟠 ขั้นที่ 5: ปุ่ม Action จริง "ยืนยันตำแหน่งปลายทางถูกต้อง" (ใช้หลังบันทึกแล้ว + ข้อความยืนยัน)

> ปุ่มนี้อยู่บน **หน้ารายละเอียด (Detail) และแถวตาราง** ไม่ได้อยู่ในฟอร์ม (AppSheet ไม่รองรับปุ่มในฟอร์ม — ดูหัวข้อ 3.2) ใช้ตอน: บันทึกงานไปแล้วด้วยการยืนยันมือ แล้วหัวหน้า/supervisor ต้องการยืนยันซ้ำ หรือยืนยันย้อนหลัง

**จุดแก้:** `Behavior ▸ Actions ▸ "+ New Action"` แล้วตั้งค่า:

| ช่องตั้งค่า | ค่าที่ต้องใส่ |
|---|---|
| **Action name** | `ยืนยันตำแหน่งปลายทางถูกต้อง` |
| **For a record of** | `SCGนครหลวงJWDภูมิภาค` |
| **Do this** | `Data: set the values of some columns in this row` |
| **Set these columns** | `ยืนยันตำแหน่ง_ด้วยตนเอง` = `TRUE` |
| **Only if this condition is true** | *(สูตรด้านล่าง)* |
| **Needs confirmation?** | **เปิด (ON)** ✅ |
| **Confirmation message** | *(สูตรด้านล่าง)* |
| **Prominence** | `Display_Inline` (ให้เห็นเป็นปุ่มในหน้ารายละเอียด/แถวตาราง) |

**สูตร "Only if this condition is true" (copy ทั้งกล่อง):**

```
AND(
  ISNOTBLANK([SM_Link_SCG].[LatLong_Actual]),
  ISNUMBER([ระยะห่างพิกัดจริง_เมตร]),
  [ระยะห่างพิกัดจริง_เมตร] > 20,
  [ยืนยันตำแหน่ง_ด้วยตนเอง] <> TRUE
)
```

**สูตร "Confirmation message" (copy ทั้งกล่อง) — นี่คือข้อความ "มีแก้ไข โดยคนนี้" ที่คุณต้องการ:**

```
CONCATENATE(
  "ยืนยันว่าพิกัด [จุดส่งสินค้าปลายทาง] ปัจจุบันถูกต้อง?",
  " — ระบบจะบันทึกว่า: มีการยืนยันแก้ไข โดย ", USEREMAIL(),
  " เมื่อ ", TEXT(NOW(), "dd/mm/yyyy HH:mm"),
  " | ปลายทาง: ", [ชื่อปลายทาง]
)
```

**อ่านสูตร:** ปุ่มจะโผล่ **เฉพาะแถวที่ห่างเกิน 20 เมตรและยังไม่เคยยืนยัน** — ตอนกดจะขึ้นกล่องยืนยันบอกชัดว่า "ใคร" ยืนยัน "เมื่อไร" "ที่ปลายทางไหน" ก่อนบันทึกจริง

**ตรวจว่าแก้สำเร็จ:** `Behavior ▸ Actions` มี Action ใหม่ชื่อ `ยืนยันตำแหน่งปลายทางถูกต้อง` อยู่ในกลุ่มของตาราง SCGนครหลวงJWDภูมิภาค → เปิดแอปเข้าแถวที่ห่างเกิน 20 ม. (หลังบันทึกแล้ว) → ต้องเห็นปุ่ม และเมื่อกดต้องขึ้นกล่องข้อความยืนยันพร้อมอีเมลของคุณ

## 🎨 ขั้นที่ 6: Format Rule — แถวสีส้ม "มีแก้ไขพิกัด (ยืนยันด้วยตนเอง)"

ให้ทุกคนที่เปิดดูเห็นทันทีว่าแถวนี้ "มีการยืนยันแก้ไขพิกัด" โดยไม่ต้องเปิดไล่คอลัมน์

**จุดแก้:** `Format Rules ▸ + (New Rule)` แล้วตั้งค่า:

| ช่องตั้งค่า | ค่าที่ต้องใส่ |
|---|---|
| **Rule name** | `มีแก้ไขพิกัด_ยืนยันด้วยตนเอง` |
| **For this data** | `SCGนครหลวงJWDภูมิภาค` |
| **If this condition is true** | `[ยืนยันตำแหน่ง_ด้วยตนเอง] = TRUE` |
| **Background color** | `#FFA500` (ส้ม) |
| **Text color** | `#000000` (ดำ) |
| **Text style** | เปิด Bold |
| **Position** | `Entire row` (ไฮไลต์ทั้งแถว) |

**สำคัญ:** ลาก Rule นี้ขึ้นไปไว้ **ใกล้ที่สุดของลิสต์** (Format Rule ตัวบนมีสิทธิ์ชนะตัวล่าง) — อย่าให้ Rule "ผลการตรวจสอบงานส่ง_FAIL" ทับสีของเรา

**ตรวจว่าแก้สำเร็จ:** เปิดแอปไปที่มุมมองตาราง/แผนที่ของชีต SCGนครหลวงJWDภูมิภาค → แถวที่เคยยืนยันมือต้องเป็นสีส้มทั้งแถว

## 🔔 ขั้นที่ 7 (เสริม แนะนำ): Bot แจ้งเตือนเมื่อมีการยืนยันพิกัดมือ

ให้หัวหน้า/หลังบ้านรู้ทันทีว่า "มีแก้ไข โดยคนนี้" — แอปคุณมีระบบบอทอยู่แล้ว จึงเพิ่มได้ตามสไตล์เดิม

**จุดแก้:** `Automation ▸ Bots ▸ + New Bot` แล้วตั้งค่า:

**1) Event:**

| ช่อง | ค่า |
|---|---|
| Event type | `Data Change` |
| Data | `SCGนครหลวงJWDภูมิภาค` |
| Condition | *(สูตรด้านล่าง)* |

```
AND(
  [ยืนยันตำแหน่ง_ด้วยตนเอง] = TRUE,
  [_THISROW_BEFORE].[ยืนยันตำแหน่ง_ด้วยตนเอง] <> TRUE
)
```

**2) Process → Create a new step → Run a task → Send a notification:**

| ช่อง | ค่า |
|---|---|
| Notify to | อีเมลหัวหน้า/หลังบ้าน (หรือ `Announcements` ตามระบบแจ้งเดิมของคุณ) |
| Notification body | *(สูตรด้านล่าง)* |

```
CONCATENATE(
  "⚠️ มีการยืนยันพิกัดปลายทางด้วยตนเอง",
  " | ปลายทาง: ", [ชื่อปลายทาง],
  " | Invoice: ", IF(ISNOTBLANK([Invoice No]), INDEX([Invoice No], 1), "-"),
  " | โดย: ", [ยืนยันตำแหน่ง_โดย],
  " | เวลา: ", TEXT([ยืนยันตำแหน่ง_เวลา], "dd/mm/yyyy HH:mm")
)
```

> 💡 ถ้าทีมคุณรับแจ้งผ่าน Telegram อยู่แล้ว (ตามระบบบอทเดิม) ให้คงช่องทางเดิมไว้แล้ววางสูตรข้อความด้านบนแทนได้เลย — เนื้อหาเหมือนกัน

**ตรวจว่าแก้สำเร็จ:** ทำเคสทดสอบเลข 4 ในขั้นที่ 8 แล้วรอรับการแจ้งเตือน

## 🧪 ขั้นที่ 8: ทดสอบให้ครบ 5 เคสก่อนใช้จริง

> ทดสอบบน **สำเนาแอป (Copy app)** หรือโหมดพรีวิวก่อนเสมอ ถ้าทำบนแอปจริงให้ทดลองกับงานจำนวนน้อยและแจ้งทีมล่วงหน้า

| เคส | สถานการณ์ที่จำลอง | ผลที่ต้องได้ ✅ |
|---|---|---|
| 1 | `LatLong_Actual` ในชีตตารางงานประจำวัน = ว่าง | บันทึกได้ปกติ ไม่มีสวิตช์โผล่ (ไม่มีพิกัดให้เทียบ) |
| 2 | ยืนงานใกล้ร้านจริง ห่าง ≤ 20 เมตร | บันทึกได้เลย ไม่มีสวิตช์โผล่ ไม่มีข้อความเตือน |
| 3 | อยู่ไกล > 20 เมตร **ไม่เปิดสวิตช์** | **SAVE ติด** + ข้อความเตือนบอกระยะจริง + สวิตช์โผล่ให้เห็น |
| 4 | อยู่ไกล > 20 เมตร **เปิดสวิตช์** แล้วบันทึก | SAVE ผ่าน + `ยืนยันตำแหน่ง_โดย` = อีเมลผู้ทดสอบ + `ยืนยันตำแหน่ง_เวลา` = เวลาปัจจุบัน + แถวเป็นสีส้ม + (ถ้าทำขั้นที่ 7) ได้รับแจ้งเตือน |
| 5 | เปิดแถวที่ยืนยันแล้ว กดปุ่ม Action `ยืนยันตำแหน่งปลายทางถูกต้อง` | ขึ้นกล่อง "มีการยืนยันแก้ไข โดย [อีเมล] เมื่อ [เวลา]" → กดตกลงแล้วค่าคอลัมน์อัปเดต (เคสนี้ใช้แถวที่ห่างเกินแต่ยังไม่เคยยืนยัน) |

**ตรวจข้อมูลใน Google Sheet:** หลังเคส 4 เปิดชีต `SCGนครหลวงJWDภูมิภาค` ดูแถวที่ทดสอบ — ต้องเห็นค่า `ยืนยันตำแหน่ง_ด้วยตนเอง` = TRUE, `ยืนยันตำแหน่ง_โดย` = อีเมล, `ยืนยันตำแหน่ง_เวลา` = วันเวลา บันทึกถาวรในชีต (ปิดแอปเปิดใหม่ค่ายังอยู่)

## ⚠️ 9) ข้อควรระวังสำคัญ (อ่านทั้งหมดก่อนใช้งานจริง)

1. **ความแม่นยำ GPS มือถือ:** อุปกรณ์พกพาเพี้ยนได้ 5-15 เมตร (โดยเฉพาะในอาคาร/ใต้หลังคา) เกณฑ์ 20 เมตรจึงเหมาะกับงานส่งนอกอาคาร ถ้าพบว่าพนักงานโดนบล็อกบ่อยเกินจริง ให้ขยับเกณฑ์เป็น 30 เมตร — แก้เลข `20` ใน **3 จุด**: Valid_If (ขั้นที่ 3), Show_If สวิตช์ (ขั้นที่ 2-A), เงื่อนไขปุ่ม Action (ขั้นที่ 5)
2. **พฤติกรรมจับคู่ Invoice แรก:** `SM_Link_SCG` ของเดิมจับคู่ด้วย Invoice No ตัวแรกที่เจอในชีตตารางงานประจำวัน — ถ้าแถว SCG หนึ่งแถวมีหลาย Invoice และแต่ละใบมีพิกัดคนละจุด ระบบจะเทียบกับพิกัดของ Invoice แรก (พฤติกรรมเดิมของแอป ไม่ใช่ข้อผิดพลาดใหม่)
3. **สวิตช์จะค้าง TRUE เป็นประวัติ:** ตั้งใจให้เป็นอย่างนั้น (เก็บหลักฐานว่าใครยืนยัน) ถ้าผู้ใช้แก้พิกัดให้ถูกต้องในภายหลัง flag ไม่ลบเอง — ต้องการให้รีเซ็ตอัตโนมัติเมื่อพิกัดเปลี่ยน ให้เปลี่ยน App formula ของสวิตช์เป็นขั้นสูง (มือใหม่ไม่แนะนำ):
   ```
   IF(
     AND(ISNOTBLANK([_THISROW_BEFORE].[ยืนยันตำแหน่ง_ด้วยตนเอง]),
         [จุดส่งสินค้าปลายทาง] <> [_THISROW_BEFORE].[จุดส่งสินค้าปลายทาง]),
     FALSE,
     [_THISROW_BEFORE].[ยืนยันตำแหน่ง_ด้วยตนเอง]
   )
   ```
   ⚠️ ถ้าเปลี่ยนเป็นสูตรนี้ สวิตช์จะกดเองไม่ได้แล้ว — โหมดนี้ต้องใช้กับปุ่ม Action ขั้นที่ 5 เท่านั้น จึงแนะนำให้คงสวิตช์กดมือไว้ตามสูตรหลัก
4. **Security filter ทำให้ deref เห็นเฉพาะงานของตัวเอง:** ทั้ง 2 ตารางกรองด้วย `[Email พนักงาน] = USEREMAIL()` — ถ้าแถวในตารางงานประจำวันถูกสร้างด้วยอีเมลอื่น (เช่น หลังบ้านป้อนแทน) พนักงานจะมองไม่เห็นแถวนั้น → `[SM_Link_SCG].[LatLong_Actual]` เป็นค่าว่าง → ระบบ **ข้ามการตรวจ** (ไม่บล็อก) ถ้าอยากให้เข้มขึ้น (ห้ามบันทึกเมื่อหาพิกัดอ้างอิงไม่เจอ) ให้ตัดบรรทัด `ISBLANK([SM_Link_SCG].[LatLong_Actual]),` ออกจากสูตร Valid_If แต่ต้องมั่นใจว่าข้อมูลชีตตารางงานประจำวันถูกกรอกครบทุกวันจริง ๆ ก่อน
5. **อย่าเผลอตั้ง Sensitive data ให้ `ยืนยันตำแหน่ง_โดย`:** คอลัมน์อีเมลอื่นในแอปถูกแนะนำให้ตั้ง Sensitive data (PDPA) — แต่คอลัมน์นี้ควรเปิดให้เห็นได้ เพราะหน้าที่ของมันคือ "ประกาศว่าใครยืนยัน" จะตั้ง Sensitive ก็ได้ถ้าองค์กรต้องการ แต่จะซ่อนจากการ export ด้วย
6. **ทดสอบก่อนขึ้นแอปจริงเสมอ:** สูตรทั้งหมดควรทดสอบในสำเนาแอป (Copy app) ก่อน โดยเฉพาะขั้นที่ 3 เพราะแตะคอลัมน์ที่พนักงานใช้บันทึกงานทุกวัน

## ❓ 10) คำถามที่พบบ่อย (FAQ)

**ถาม: ทำไมไม่ทำเป็นปุ่มกดในฟอร์มเลย แบบที่เห็นแอปอื่น?**
ตอบ: AppSheet ไม่รองรับปุ่ม Action ใน Form view อย่างเป็นทางการ (ยืนยันจากฟอรัมนักพัฒนาของ Google ล่าสุด) สวิตช์ Yes/No คือวิธีมาตรฐานที่ทำงานได้ 100% ทุกอุปกรณ์ และ UX ได้ผลเหมือนกัน: เห็นเตือน → กดยืนยัน → กด SAVE

**ถาม: จะเปลี่ยนเกณฑ์ 20 เมตรเป็นค่าอื่นได้มั้ย?**
ตอบ: ได้ แก้เลข `20` ใน 3 จุดตามข้อควรระวังข้อ 1

**ถาม: ทำไมใช้ `[SM_Link_SCG].[LatLong_Actual]` แทน LOOKUP?**
ตอบ: เร็วกว่าและตรงกับสถาปัตยกรรมเดิม (แอปใช้ SM_Link_SCG ดึงชื่อปลายทาง/ที่อยู่/รหัสลูกค้าอยู่แล้ว) — ใช้ LOOKUP ก็ได้ผลเดียวกัน: `LOOKUP([_THISROW].[รหัสลูกค้า], ...)` แต่จะช้ากว่าและซ้ำซ้อน เพราะ Ref มีอยู่แล้ว

**ถาม: ต้องแก้ Google Sheet เองมั้ย?**
ตอบ: ไม่ต้อง — เพิ่มคอลัมน์ใน AppSheet Editor ตามขั้นที่ 2 แล้ว AppSheet เติมหัวคอลัมน์ให้เอง ถ้าไม่โผล่ให้ทำตามคำแนะนำท้ายขั้นที่ 2 (พิมพ์หัวคอลัมน์เอง + Regenerate schema)

**ถาม: แผนที่ที่มีอยู่ต้องแก้มั้ย?**
ตอบ: ไม่ต้อง — Map view โชว์คอลัมน์ `จุดส่งสินค้าปลายทาง` เหมือนเดิม ระบบตรวจระยะเป็น "ชั้นตรวจสอบ" ที่อยู่เบื้องหลังการบันทึก แยกจากการแสดงผลแผนที่ (อยากให้แถวที่ยืนยันมือเด่นบนแผนที่ด้วย ให้พึ่ง Format Rule ขั้นที่ 6 ซึ่งไฮไลต์ทั้งแถวในทุกมุมมอง)

**ถาม: ถ้าพนักงานเปิดสวิตช์ยืนยันทุกครั้งโดยไม่ดู มีวิธีจับมั้ย?**
ตอบ: มี — ขั้นที่ 7 (Bot แจ้งเตือน) จะดันรายงานไปหาหัวหน้าทุกครั้ง และ Format Rule ขั้นที่ 6 ทำให้แถวสีส้มตรวจสอบย้อนหลังได้ นอกจากนี้คอลัมน์ `ผลการตรวจสอบงานส่ง` เดิมของแอป (ระบบ PASS/WARNING/FAIL) ยังทำงานควบคู่อยู่

**ถาม: ทำแล้วมีผลกับตารางอื่นที่ใช้ จุดส่งสินค้าปลายทาง มั้ย (เช่น สรุป_Shipment)?**
ตอบ: ไม่มี — เราแต่ง Valid_If ที่คอลัมน์ (เช็คตอนบันทึก) และเพิ่มคอลัมน์ใหม่เท่านั้น ไม่ได้เปลี่ยนค่าหรือชนิดของคอลัมน์เดิม ตารางอื่นที่อ่านค่าจึงได้ข้อมูลเหมือนเดิมทุกอย่าง

## ✅ 11) เช็คลิสต์รวมของฟีเจอร์นี้

- [ ] ขั้นที่ 1: คอลัมน์เสมือน `ระยะห่างพิกัดจริง_เมตร` (Decimal) พร้อมสูตร DISTANCE×1000
- [ ] ขั้นที่ 2-A: คอลัมน์จริง `ยืนยันตำแหน่ง_ด้วยตนเอง` (Yes/No, Initial =FALSE, Show_If เกิน 20 ม.)
- [ ] ขั้นที่ 2-B: คอลัมน์จริง `ยืนยันตำแหน่ง_โดย` (Email, App formula USEREMAIL)
- [ ] ขั้นที่ 2-C: คอลัมน์จริง `ยืนยันตำแหน่ง_เวลา` (DateTime, App formula NOW)
- [ ] ขั้นที่ 3: แทนที่ Valid_If ของ `จุดส่งสินค้าปลายทาง` ด้วยสูตร merge + ตั้งข้อความ INVALID VALUE ERROR
- [ ] ขั้นที่ 5: สร้าง Action `ยืนยันตำแหน่งปลายทางถูกต้อง` (Set values + Confirmation + เงื่อนไข > 20 ม.)
- [ ] ขั้นที่ 6: สร้าง Format Rule `มีแก้ไขพิกัด_ยืนยันด้วยตนเอง` (สีส้ม, ทั้งแถว, ลำดับบนสุด)
- [ ] ขั้นที่ 7 (เสริม): Bot แจ้งเตือนเมื่อมีการยืนยันมือ
- [ ] ขั้นที่ 8: ทดสอบครบ 5 เคส + ตรวจค่าถูกเก็บใน Google Sheet
