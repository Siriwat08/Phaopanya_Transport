## 🚨 ปัญหาระดับตาราง (แก้ก่อนรายคอลัมน์)

### 🚨 ปัญหา 1: 🟠 [MEDIUM] ตารางไม่มี Security filter → ผู้ใช้ทุกบทบาทเห็นข้อมูลทุกแถว

- **ทำไมสำคัญ:** Security filter คือด่านตัดข้อมูลที่ฝั่งเซิร์ฟเวอร์ ถ้าไม่มี ทุกแถวถูกดาวน์โหลดลงเครื่องทุกผู้ใช้ แม้หน้าจอซ่อนไว้ก็หลุดผ่านวิวอื่นได้
- **วิธีแก้ทีละขั้น (จุดแก้:** `Data ▸ Tables ▸ คลิกตารางนี้ ▸ ช่อง "Security filter"`):**
   1. คลิกช่อง "Security filter" (ถ้าไม่มีช่องนี้ คลิก + สร้างในกลุ่ม Table settings หรือแก้ผ่าน "Table properties")
   2. วางสูตรด้านล่าง — ปรับ [Email พนักงาน] เป็นชื่อคอลัมน์อีเมลของตารางนี้ให้ตรง
   3. กด Save — ทดสอบด้วยบัญชี USER ว่าเห็นเฉพาะแถวของตัวเอง

**สูตรที่ใช้ (คัดลอกไปวางได้):**

```
=OR(USERROLE() = "ADMIN", [Email พนักงาน] = USEREMAIL())
```

- **ตรวจว่าแก้สำเร็จ:** ล็อกอินด้วย USER แล้วตรวจว่าเห็นเฉพาะแถวของตัวเอง

### 🚨 ข้อค้นพบ 2 (วิเคราะห์พื้นฐาน) [ต้องปรับปรุง] ตารางนี้ไม่มี Security filter ทำให้ผู้ใช้ทุกบทบาท (USER) เห็นข้อมูลทั้งหมด

- **ผลต่องาน:** ข้อมูลข้ามผู้ใช้หลุดรั่ว — ทั้งข้อมูลงานและข้อมูลลูกค้า
- **วิธีแก้:** ตั้ง Security filter ให้เหมือนตารางหลักของแอป

**สูตรแนะนำ:**

```
=OR(USERROLE() = "ADMIN", [Email พนักงาน] = USEREMAIL())
```

**สูตร/ค่าที่ใช้ (คัดลอกไปวางได้):**

```

```

- **ตรวจว่าแก้สำเร็จ:** ลองแก้คีย์ในแอป ต้องแก้ไม่ได้

#### ข้อค้นพบ 2 (จากการวิเคราะห์พื้นฐาน): 🟡 [พอใช้] คอลัมน์ Key ไม่ได้ล็อกการแก้ไข → ผู้ใช้แก้หรือคัดลอก Key ได้ ทำให้ข้อมูลอ้างอิงผิด

- **หลักฐาน:** Key = Yes, Read-Only = No
- **ผลต่องาน:** ความสัมพันธ์ระหว่างตารางเสียหาย
- **วิธีแก้:** ตั้ง Read-Only = Yes สำหรับคอลัมน์ Key

- **วิธีตรวจ:** เปิดคอลัมน์ `ID_น้ำมันดีเซล` ของตาราง `ราคาน้ำมันดีเซล` ในแอป แล้วตรวจว่าปัญหาที่อธิบายไว้ ยังเกิดอยู่จริงหรือไม่

#### ข้อค้นพบ 3 (จากการวิเคราะห์พื้นฐาน): 🔴 [เสี่ยง] Initial value เขียนเป็น 'UNIQUEID()' ไม่มีเครื่องหมาณ '=' → ค่าที่บันทึกเป็นข้อความ 'UNIQUEID()' เหมือนกันทุกแถว ทั้งที่คอลัมน์นี้เป็น key ของตารางราคาน้ำมันที่ถูกอ้างอิงจากสูตร 'เรทดีเซล' และจาก D03

- **หลักฐาน:** initial_value = 'UNIQUEID()' (ไม่มี '=') ; column key=Yes
- **ผลต่องาน:** แถวราคาน้ำมันทุกแถวมี key เดียวกัน → ตรวจสอบ/อ้างอิง/ลบแถวเฉพาะไม่ได้ และถ้ามีการใช้ Ref/Unique ในอนาคตจะเลือกแถวผิด
- **วิธีแก้:** แก้เป็น '=UNIQUEID()' และแก้ข้อมูลเดิมให้แต่ละแถวมีค่าไม่ซ้ำ

**สูตรแนะนำ (คัดลอกไปวางได้ — ปรับชื่อคอลัมน์ให้ตรงแอปจริงก่อนใช้):**

```
=UNIQUEID()
```

- **วิธีตรวจ:** เปิดคอลัมน์ `ID_น้ำมันดีเซล` ของตาราง `ราคาน้ำมันดีเซล` ในแอป แล้วตรวจว่าปัญหาที่อธิบายไว้ ยังเกิดอยู่จริงหรือไม่

#### ข้อค้นพบ 1 (จากการวิเคราะห์พื้นฐาน): 🔴 [ต้องปรับปรุง] คีย์วันที่ของตารางราคาน้ำมันดีเซล ไม่มี Valid_If กันวันที่ซ้ำ ไม่บังคับว่าต้องมี และไม่มีการกำหนดวันที่มีผล → สูตร 'เรทดีเซล' เลือกราคาด้วย 'วันที่ = UsePriceDate' และ fallback เป็น 'วันที่ 25 ของเดือนก่อน' → ถ้าวันที่ไม่มีตรงกับที่ใช้ เรทจะว่าง/0 และราคาตามระยะทางจะเป็น 0

- **หลักฐาน:** ไม่มีสูตร (type=Date) — ถูกอ้างใน 'เรทดีเซล' =IF(... ANY(SELECT(ราคาน้ำมันดีเซล[ราคา/หน่วย], [วันที่] = ...)) ...)
- **ผลต่องาน:** ถ้าวันที่ซ้ำ จะได้ราคาของแถวแรกแบบไม่แน่นอน ถ้าวันที่ไม่ครบตามรอบที่บอท/ผู้ดูแลกำหนด ราคาทั้งระบบจะตกไปทางเงียบ ๆ
- **วิธีแก้:** บังคับวันที่ไม่ซ้ำ (Valid_If), บังคับ Required_If, กำหนดวันที่มีผล/ผู้บันทึก และเพิ่มคอลัมน์ 'วันที่อ้างอิงราคา (ใช้จริง)' ให้ตรงกับกฎ fallback แทนการฝัง 'วันที่ 25' ในสูตร

- **วิธีตรวจ:** เปิดคอลัมน์ `วันที่` ของตาราง `ราคาน้ำมันดีเซล` ในแอป แล้วตรวจว่าปัญหาที่อธิบายไว้ ยังเกิดอยู่จริงหรือไม่

- **ทำไมสำคัญ:** ข้อมูลเงินไม่มีด่านกันพลาด สรุปยอดวางบิลผิด ตรวจสอบย้อนหลังยาก
- **วิธีแก้ทีละขั้น (จุดแก้:** `Data ▸ Tables ▸ คลิกตารางนี้ ▸ คลิกไอคอนดินสอ ที่คอลัมน์นี้ ▸ Valid_If`):**
   1. กลุ่ม "Data validity" → คลิกช่อง "Valid_If"
   2. วางสูตรด้านล่าง (ปรับเพดานตามงานจริง)
   3. ใส่ข้อความ "Error message if invalid" เช่น "กรุณากรอกตัวเลข 0 ถึง 1,000,000"

**สูตร/ค่าที่ใช้ (คัดลอกไปวางได้):**

```
AND([_THIS] >= 0, [_THIS] < 1000000)
```

- **ตรวจว่าแก้สำเร็จ:** ลองกรอก -1 ในช่องนี้ แอปต้องแจ้ง error
