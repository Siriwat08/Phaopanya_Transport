# 📚 ดัชนีคู่มือแก้ไข — เผ่าปัญญาทรานสปอร์ต (ครบ 30 ตาราง)

> คู่มือแก้ไขแบบ **ทีละขั้นสำหรับมือใหม่** ครบทุกตารางหลัก ทุกคอลัมน์ (610 คอลัมน์) พร้อมสูตร copy-paste

> 🧒 **เพิ่งเริ่ม / อ่านคำเทคนิคแล้วงง?** อ่าน [33-คู่มืออธิบายง่ายมาก-อ่านไฟล์นี้ก่อน.md](33-คู่มืออธิบายง่ายมาก-อ่านไฟล์นี้ก่อน.md) ก่อน — สอนตั้งแต่ "AppSheet คืออะไร" แบบเด็ก 12 ขวบเข้าใจ แล้วค่อยกลับมาที่นี่

**วิธีใช้คู่มือนี้:**

1. มือใหม่: อ่าน `33-คู่มืออธิบายง่ายมาก-อ่านไฟล์นี้ก่อน.md` ก่อน (อธิบายทุกคำศัพท์แบบเด็ก 12 ขวบเข้าใจ) → จากนั้นอ่าน `00-รายงานวิเคราะห์และแผนปรับปรุง.md` เพื่อเข้าใจภาพรวมและลำดับการแก้ (บั๊ก → เสี่ยง → ปรับปรุง)
2. เลือกไฟล์ตารางที่ต้องแก้จากตารางด้านล่าง (ควรเริ่มจากตารางที่มี 🔴/🟠 เยอะ และเป็นตารางหลักของการวางบิลก่อน)
3. เปิดไฟล์ อ่านหัวข้อ "ทางเข้าแก้ไขใน AppSheet Editor" → ทำตามขั้น 1-6
4. แก้ปัญหาระดับตารางก่อนเสมอ แล้วค่อยไล่คอลัมน์จากบนลงล่าง
5. กด ✅ ในช่องเช็คลิสต์ท้ายไฟล์ทุกครั้งที่แก้เสร็จ และทดสอบในแอปจริงก่อนขึ้นเครื่องผู้ใช้
