   3. Save แล้วทดสอบสร้างแถวใหม่ คีย์ต้องถูกสร้างอัตโนมัติ

```

```

**สถานะ: 🟠 ต้องปรับปรุง** — พบปัญหา 3 ข้อ

#### ข้อค้นพบ 1 (จากการวิเคราะห์พื้นฐาน): 🟠 [ต้องปรับปรุง] ใช้คอลัมน์ Yes/No แทนปุ่ม Action จริง ทำให้ผู้ใช้ 'กดส่ง' เองไม่ได้ และบังคับให้แนบครบ 3 รูป

- **หลักฐาน:** initial_value = '=false'; Valid_If = '=OR(ISBLANK([กดปุ่มนี้เพื่อส่งข้อมูลแจ้งปัญหา]), NOT([กดปุ่มนี้เพื่อส่งข้อมูลแจ้งปัญหา]))'; Show_If = '=AND(ISNOTBLANK([รูป1]), ISNOTBLANK([รูป2]), ISNOTBLANK([รูป3]), NOT([กดปุ่มนี้เพื่อส่งข้อมูลแจ้งปัญหา]))'
- **ผลต่องาน:** Valid_If อนุญาตเฉพาะค่า FALSE/ว่าง → ผู้ใช้ที่เปิดแอปเป็น USER ติ๊ก TRUE ไม่ได้ ต้องรอบอทตั้งค่าให้ ซึ่งทำให้พนักงานรู้สึกว่าปุ่มกดไม่ได้ และ Show_If บังคับรูป 3 ใบครบเสมอ แม้เคส 'ร้านปิด' หรือ 'ลูกค้าไม่รับสาย' ไม่ต้องใช้รูป 3 ใบ
- **วิธีแก้:** เพิ่มภาระงานให้พนักงาน (ต้องหารูป 3 ใบทุกเคส) และเสี่ยงทำให้ผู้ใช้กดปุ่มแล้วไม่มีอะไรเกิดขึ้น (เพราะ Valid_If ไม่ยอมให้ TRUE)

**สูตรแนะนำ (คัดลอกไปวางได้ — ปรับชื่อคอลัมน์ให้ตรงแอปจริงก่อนใช้):**

```

```

- **วิธีตรวจ:** เปิดคอลัมน์ `กดปุ่มนี้เพื่อส่งข้อมูลแจ้งปัญหา` ของตาราง `แจ้งปัญหาระหว่างวัน` ในแอป แล้วตรวจว่าปัญหาที่อธิบายไว้ ยังเกิดอยู่จริงหรือไม่

**สถานะ: 🟠 ต้องปรับปรุง** — พบปัญหา 1 ข้อ

#### ข้อค้นพบ 1 (จากการวิเคราะห์พื้นฐาน): 🟠 [ต้องปรับปรุง] ไม่มี Required_If (บังคับเลือกประเภทปัญหา) และตัวเลือกเป็นประโยคเต็มยาว ไม่มีรหัสหมวดสั้นให้กรอง/รายงาน

- **หลักฐาน:** EnumValues มี 12 รายการ เช่น 'สินค้าชำรุด ตอนขึ้นงาน แจ้งคลังตรวจสอบแล้วทางคลังไม่เซ็นรับทราบให้ แจ้งเพื่อทราบครับ', 'ปัญหาอื่นๆๆ *ใส่ปัญหาในหมายเหตุ*'; Valid_If = '' (ว่าง) และ Required_If = null
- **ผลต่องาน:** ส่งเคสได้โดยไม่ระบุประเภทปัญหา → รายงาน 'ปัญหาอะไรบ่อยที่สุด' ทำไม่ได้ และข้อความ Telegram ต้องแสดงประโยคยาวแบบไม่มีรหัสจำแนก
- **วิธีแก้:** เพิ่ม Required_If = TRUE (หรือบังคับเฉพาะเมื่อยังไม่มีหมายเหตุ) และแยกเป็น 2 คอลัมน์: 'หมวดปัญหา' (รหัสสั้น เช่น สินค้าชำรุด/ลูกค้าไม่รับ/รถมีปัญหา) กับ 'รายละเอียดปัญหา' (ข้อความอิสระ) แล้วให้ข้อความ Telegram ใช้รหัสหมวด

**สูตรแนะนำ (คัดลอกไปวางได้ — ปรับชื่อคอลัมน์ให้ตรงแอปจริงก่อนใช้):**

```
=ISBLANK([ข้อมูลการแจ้งปัญหา])
```

- **วิธีตรวจ:** เปิดคอลัมน์ `ข้อมูลการแจ้งปัญหา` ของตาราง `แจ้งปัญหาระหว่างวัน` ในแอป แล้วตรวจว่าปัญหาที่อธิบายไว้ ยังเกิดอยู่จริงหรือไม่
